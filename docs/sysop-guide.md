# 管理者 (SYSOP) の操作

## SYSOP になるには

- 最初にオンラインで登録した会員は、自動で SYSOP になります。
- コマンドラインから `null-bbs useradd ID ハンドル --sysop` で追加することもできます。
- 管理コンソールの会員管理でレベルを 100 にすれば、SYSOP にできます。

会員番号は次のように割り当てます。

| 会員番号 | 用途 |
|---|---|
| 0 | ゲスト |
| 1 | SYSOP (最初に登録した人、または最初に `--sysop` で追加した人) |
| 2〜9 | 予約 (自動では割り当てない) |
| 10〜 | 一般の会員 (登録順) |

1 番が埋まったあとに追加した SYSOP には、10 番以降の番号が付きます。

会員のレベルは次のとおりです。

| レベル | 名前 | できること |
|---|---|---|
| 0 | ゲスト | 掲示板を読む、チャット |
| 10 | 会員 | 書き込み、メール、アップロード |
| 50 | サブ SYSOP | (予約。今は会員と同じ) |
| 100 | SYSOP | お知らせへの書き込み、他人の記事やファイルの削除、SYSOP メニュー |

## 管理コンソール

`null-bbs` を `--headless` なしで起動すると、その端末が管理コンソールになります。


### 回線画面

| キー | 動作 |
|---|---|
| ↑ ↓ / PgUp PgDn | 回線を選ぶ |
| Enter / M | 選んだ回線の画面を見る (モニタ) |
| K | 選んだ回線を切断する |
| B | 全体放送 (接続中の全員にメッセージを送る) |
| U | 会員管理 |
| O | ボード管理 |
| A | 全回線を表示するか、使用中とモデム回線だけにするかを切り替える |
| ? | ヘルプ |
| Q | 終了 (接続中の人には知らせてから切断します) |

回線の状態は色で分かれます。

| 状態 | 意味 |
|---|---|
| 空き / 待機 | TCP の空き回線 / モデムが着信を待っている |
| 初期化 | モデムに初期化コマンドを送っている |
| 着信 / 接続中 | RING を受けた / ATA で応答して CONNECT を待っている |
| ログイン | 接続したが、まだログインしていない |
| 利用中 | ログインして利用している |
| 切断中 | 回線を切っている |
| エラー | ポートが開けない、モデムが応答しないなど。理由が横に出ます |

### モニタ

利用者が見ている画面を、そのまま横から見られます。モニタ中も `K` で切断、`B` で全体放送ができます。`Esc` で回線画面に戻ります。

### 会員管理 (U)

| キー | 動作 |
|---|---|
| B | 利用停止 / 停止の解除 (停止中の会員はログインできません) |
| L | レベルを変える |
| P | パスワードを再設定する |
| Esc | 戻る |

### ボード管理 (O)

| キー | 動作 |
|---|---|
| A | ボードを追加する (名前と表示名を入力) |
| D | ボードを削除する |
| Esc | 戻る |

## 回線からの SYSOP メニュー

SYSOP でログインすると、メインメニューに `9.SYSOP` が出ます。管理コンソールの前にいなくても、次の操作ができます。

| コマンド | 動作 |
|---|---|
| `B 本文` | 全体放送 |
| `K 回線番号` | 回線を切断する |
| `A` | ボードを追加する |

## システムログ

ログイン、ログオフ、書き込み、アップロード、モデムの状態などが、管理コンソールの下の欄と `null-bbs.log` に記録されます。
`RUST_LOG=debug null-bbs` のようにすると、より細かい情報が出ます。
