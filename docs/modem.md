# モデムで運用する

## つなぎかた

```
[電話回線 / 疑似交換機] ── モデム ── RS-232C ── USB シリアル変換 ── null-bbs を動かす PC
```

モデム 1 台につき、USB シリアルのポートが 1 つ必要です。回線ごとに `[[modem]]` を 1 つ書きます。

## 設定

```toml
[[modem]]
line = 1                          # 回線番号 (1〜max_lines)。TCP はこれ以外の番号を使います
path = "/dev/cu.usbserial-XXXX"   # macOS は cu.*、Linux は /dev/ttyUSB0 など
baud = 9600                       # パソコンとモデムの間の速度 (DTE 速度)
flow = "hardware"                 # none / hardware (RTS/CTS) / software (XON/XOFF)
init = ["ATZ", "ATE0V1Q0X4&C1&D2S0=0"]
answer = "manual"                 # manual / auto
rings = 1                         # manual のとき、何回目の RING で応答するか
connect_timeout_secs = 60
connect_delay_ms = 500            # CONNECT からログイン画面を出すまでの待ち時間
carrier = "both"                  # dcd / text / both
hangup = "dtr"                    # dtr / escape
```

### 初期化コマンド (init)

1 つずつ送って、それぞれ `OK` が返るのを待ちます。3 回送っても返らなければ、30 秒後にやり直します。
既定値の意味は次のとおりです。

| コマンド | 意味 |
|---|---|
| `ATZ` | モデムを保存済みの設定に戻す |
| `E0` | コマンドのエコーをしない (文字はホスト側でエコーするため) |
| `V1` `Q0` | 結果を「OK」「CONNECT」などの文字で返す |
| `X4` | 詳しい結果コード (接続速度など) を返す |
| `&C1` | キャリアがあるときだけ DCD 信号を ON にする |
| `&D2` | DTR 信号が OFF になったら回線を切る |
| `S0=0` | 自動では着信しない (null-bbs が `ATA` で応答する) |

モデムによって使えるコマンドが違うので、合わせて変えてください。

### 着信のしかた (answer)

- `manual`: モデムからの `RING` を数え、`rings` 回目で `ATA` を送って応答します。
- `auto`: モデムの自動着信にまかせます。init に `S0=1` を入れてください。null-bbs は `CONNECT` だけを待ちます。

`RING` が安定して届かない環境では、`auto` のほうが確実です。たとえば、ベル信号の弱い疑似交換機がこれに当たります。

### キャリア断の検出 (carrier)

- `dcd`: DCD 信号が OFF になったら切れたと判断します。モデムを `&C1` にしておく必要があります。
- `text`: 受信データの中に「NO CARRIER」が来たら切れたと判断します。
- `both`: どちらかで判断します。

USB シリアル変換によっては、DCD 信号が配線されていないものがあります (安価な CH340 など)。その場合は `text` にしてください。

### 切断のしかた (hangup)

- `dtr`: DTR 信号を 0.6 秒 OFF にします。モデムを `&D2` にしておく必要があります。
- `escape`: 1.2 秒待って `+++` を送り、さらに 1.2 秒待って `ATH0` を送ります。DTR が使えないときに選びます。

切断したあとは、初期化コマンドを送り直してから次の着信を待ちます。

## 疑似交換機で試す

実際の電話回線が無くても、疑似交換機 (秋月電子の「(新)PIC 簡易疑似電話交換機キット」など) を使えば、モデム 2 台で通信を試せます。
片方のモデムを null-bbs に、もう片方を null-term などの端末につなぎます。

- 端末側から `ATDT0` で発信します (疑似交換機はダイヤル番号を無視します)。
- 56k モデムと 2400bps モデムを組み合わせるときは、56k モデム側を `AT+MS=2,1,300,2400` のように、上限だけ下げてください。速度を固定すると、つながらないことがあります。
- 疑似交換機の電源投入時や RESET を押したときに、どちらかのモデムがオフフック (回線をつかんだ状態) だと、疑似交換機は内線モードになります。内線モードでは発信音もベルも出ないので、RESET は両方のモデムがオンフックのときに押してください。

## ハードウェアなしで試す

`scripts/fake_modem_test.py` は、pty で偽のモデムを作って、次の流れを通しで確かめるテストです。

1. 初期化
2. `RING` → `ATA` → `CONNECT`
3. ログイン
4. キャリア断
5. 切断
6. 再初期化

```sh
cargo build
python3 scripts/fake_modem_test.py target/debug/null-bbs
```
