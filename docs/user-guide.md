# 利用者の操作

## 接続とログイン

モデムなら電話をかけて、TCP なら `telnet ホスト名 5656` でつなぎます。

```
ID を入力してください (新規登録=NEW ゲスト=GUEST):
```

- **会員登録**: `NEW` と入力し、ID (英字で始まる英数字 3〜12 文字)、ハンドル名、パスワード (4 文字以上) を決めます。登録するとそのままログインします。
- **ゲスト**: `GUEST` と入力します。掲示板を読むこととチャットだけができます。
- **会員**: ID とパスワードを入力します。

ログインすると、前回のログイン日時、未読メールの数、新着記事のあるボードが表示されます。

## メインメニュー

```
 1.掲示板 BBS    2.メール MAIL   3.チャット CHAT
 4.在室者 WHO    5.足跡 LOG      6.登録情報 PROF
 7.ファイル FILE  T.電報 TEL
 0.終了 BYE
```

番号でも英字のコマンドでも選べます。全角で打っても大丈夫です。どの画面でも次のキーが使えます。

| 入力 | 動作 |
|---|---|
| `?` | その画面のヘルプ |
| `Q` | 1 つ前の画面に戻る |
| `G` | その場で終了 (ログオフ) |

一覧が長いときは 1 画面ずつ止まります。Enter で次へ、`Q` で表示を止めます。1 画面の行数は登録情報で変えられます。

## 掲示板

ボードの番号を選んで入ります。

| コマンド | 動作 |
|---|---|
| `L` | 記事の一覧 |
| `R 番号` (または番号だけ) | 記事を読む |
| `N` | 未読の記事を順に読む |
| `W` | 記事を書く |
| `RE 番号` | 記事に返信する (題名に「Re:」が付きます) |
| `D 番号` | 自分の記事を削除する |

### 本文の入力

記事やメールの本文は 1 行ずつ入力します。

| 入力 | 動作 |
|---|---|
| `.` だけの行 | 入力を終わる |
| `/L` | ここまでの本文を見直す |
| `/A` | 書くのをやめる |

## メール

| コマンド | 動作 |
|---|---|
| `L` | 受信したメールの一覧 (`*` は未読) |
| `R 番号` | 読む |
| `S` (または `S 相手の ID`) | 送る |
| `RE 番号` | 返信する |
| `D 番号` | 削除する |

相手が接続中なら、メールが届いたことがその場で知らされます。

## チャット

`3` か `CHAT` で LOBBY に入ります。`CHAT 部屋名` で好きな部屋に入れます。入力した行がそのまま発言になります。

| コマンド | 動作 |
|---|---|
| `/W` | 部屋にいる人 |
| `/L` | 部屋の一覧 |
| `/R 部屋名` | 別の部屋に移る |
| `/T 相手 本文` | 電報を送る |
| `/Q` | チャットを出る |

## 電報

メインメニューで `T 相手 本文` と入力します。相手は回線番号 (例: `T 3 こんにちは`) か ID (例: `T goroman こんにちは`) で指定します。
電報、全体放送、チャットの発言は、入力の途中でも割り込んで表示されます。打ちかけの文字はそのまま残ります。

## 在室者と足跡

- `WHO`: 接続中の人の回線番号、ID、ハンドル、接続方法 (TCP かモデムの速度)、いる場所、接続時間
- `LOG`: 最近 20 件のログインの記録

## 登録情報

`PROF` で、ハンドル、パスワード、1 画面の行数、自己紹介を変えられます。

## ファイル

| コマンド | 動作 |
|---|---|
| `L` | ファイルの一覧 |
| `D 番号` (または番号だけ) | ダウンロード |
| `U` | アップロード (会員のみ) |
| `I 番号` | ファイルの説明 |
| `DEL 番号` | 自分が登録したファイルを削除 |

プロトコルは XMODEM、XMODEM-1K、YMODEM から選べます (Enter だけなら YMODEM)。

- **ダウンロード**: 「受信を始めてください」と出たら、通信ソフトで受信を始めます。
- **アップロード**: 「送信を始めてください」と出たら、通信ソフトから送信します。YMODEM なら複数のファイルをまとめて送れます。
- XMODEM はファイル名を送らないので、アップロードのときに名前を入力します。また XMODEM でダウンロードすると、ファイルの最後に埋め草 (0x1A) が付くことがあります。
- 転送を途中でやめるときは Ctrl-X を何回か押します。

null-term で使う場合は、`Ctrl-A u` (送信) と `Ctrl-A d` (受信) で転送できます。

## 終了

`0` か `BYE` で終了します。どの画面でも `G` ですぐに終了できます。
何も入力しないまま一定時間が過ぎたときや、接続時間の上限になったときも、自動で切断されます。
